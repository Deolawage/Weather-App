# Weather.io 🌤️

A simple weather app I built as part of my JavaScript learning journey with The Odin Project.

The idea was to build something that could fetch real weather data, process it, and display it in a clean, responsive interface. It also gave me an opportunity to practise working with APIs, asynchronous JavaScript, modules, and DOM manipulation.

## Features

- Search for weather information by location.
- View current weather conditions and temperature.
- See additional details like humidity, wind speed, visibility, and feels-like temperature.
- Check sunrise and sunset times.
- View a daily weather forecast.
- Switch between Celsius and Fahrenheit.
- Responsive layout for different screen sizes.
- Loading and error messages when fetching weather data.

## Built With

- HTML
- CSS
- JavaScript (ES6+)
- Webpack
- [Visual Crossing Weather API](https://www.visualcrossing.com/weather-api)

## What I Learned

This project helped me get more comfortable with:

- Fetching data from external APIs.
- Working with `async/await` and Promises.
- Handling API responses and errors.
- Organising JavaScript code into separate modules.
- Separating application logic from DOM manipulation.
- Dynamically creating and updating DOM elements.
- Working with temperature conversions.
- Managing multiple asynchronous requests and preventing outdated responses from updating the interface.
- Using Webpack to bundle a JavaScript application.
